# SEO Fundamentals

Comprehensive SEO content strategy for sustainable organic growth.

## Search Intent Matrix

Every piece of content must match the search intent behind target keywords.

| Intent | User Goal | Content Type | Conversion Potential |
|--------|-----------|-------------|---------------------|
| **Informational** | Learn something | Blog posts, guides, how-tos, tutorials | Low (awareness) |
| **Navigational** | Find specific site/page | Brand pages, product pages, docs | Medium (recognition) |
| **Commercial** | Research before buying | Comparisons, reviews, best-of lists | High (consideration) |
| **Transactional** | Make a purchase/action | Product pages, pricing, signup, demo | Highest (decision) |

**Critical rule:** Low volume + high intent often beats high volume + low intent. 100 visitors who convert > 10,000 who bounce.

## Keyword Prioritization

### Prioritization Quadrant

| | Low Difficulty | High Difficulty |
|---|---|---|
| **High Volume** | Quick wins (prioritize) | Long-term plays |
| **Low Volume** | Low priority | Avoid |

### Keyword Research Process
1. **Seed keywords** — core topics your audience searches for
2. **Expand** — use tools (Ahrefs, SEMrush, Google Keyword Planner) for related terms
3. **Classify intent** — map each keyword to informational/navigational/commercial/transactional
4. **Assess difficulty** — domain authority, existing competition, SERP features
5. **Prioritize** — quick wins first, long-term plays in content calendar
6. **Group into clusters** — one pillar + supporting content per topic

### Per-Piece Keyword Strategy
- **1 primary keyword** — the main target
- **2-3 secondary keywords** — related terms that support the primary
- Use primary in: title, first paragraph, one H2, meta description, URL slug
- Use secondary naturally in body copy and subheadings
- Never keyword-stuff — write for humans first

## Content Cluster Architecture

```
                PILLAR PAGE
            (Broad topic, 3,000+ words)
                    |
        +-----------+-----------+
        |           |           |
    Cluster A   Cluster B   Cluster C
    (Subtopic)  (Subtopic)  (Subtopic)
        |           |           |
    +---+---+   +---+---+   +---+---+
    |       |   |       |   |       |
  Post 1  Post 2  Post 3  Post 4  Post 5  Post 6
```

**How it works:**
- Pillar page covers the broad topic comprehensively
- Cluster pages go deep on subtopics
- All cluster pages link back to pillar page
- Pillar page links out to all cluster pages
- Internal linking passes authority throughout the cluster

**Example cluster: "Email Marketing"**
- Pillar: The Complete Guide to Email Marketing
- Cluster A: Email List Building (welcome sequences, lead magnets, opt-in forms)
- Cluster B: Email Copywriting (subject lines, CTAs, personalization)
- Cluster C: Email Analytics (open rates, click rates, A/B testing)

## On-Page SEO Checklist

### Required Elements

| Element | Rule | Example |
|---------|------|---------|
| **Title tag** | <60 chars, includes primary keyword | "Email Marketing Guide: Build, Write, Convert" |
| **Meta description** | <160 chars, includes primary keyword, compels click | "Learn email marketing from list building to conversion. Free templates included." |
| **URL slug** | Short, descriptive, includes keyword | `/email-marketing-guide` |
| **H1** | One per page, matches or reflects title tag | "The Complete Email Marketing Guide" |
| **H2/H3** | Descriptive, include secondary keywords naturally | "How to Build Your Email List" |
| **First paragraph** | Include primary keyword naturally | Mention email marketing in opening |
| **Image alt text** | Descriptive, include keyword where relevant | "email marketing funnel diagram" |
| **Internal links** | 2-3 links to related content on your site | Link to related blog posts |
| **External links** | 1-2 links to authoritative sources | Link to industry studies |

### Content-SEO Integration
- Cover topics comprehensively — search engines reward depth
- Answer "People Also Ask" questions in your content
- Structure for featured snippets: definition paragraphs, numbered lists, tables
- Update high-performing content regularly to maintain rankings

## SEO Anti-Patterns

- **Keyword stuffing** — destroys readability, triggers spam filters
- **Thin content at scale** — 100 weak pages hurt more than 10 strong ones
- **Ignoring search intent** — ranking for wrong intent = high bounce rate
- **No internal linking** — orphan pages don't get crawled or ranked
- **Publishing and praying** — content without promotion doesn't get links
- **Set and forget** — content decays without updates
- **Buying links** — short-term gains, long-term penalties
- **Copying competitors** — me-too content rarely outranks the original
- **Chasing volume over intent** — vanity traffic doesn't convert

```

```

Each cycle compounds: better data → better content → better rankings → more data.
